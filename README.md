📊 Customer Retention & Churn Analysis

An end-to-end Data Analytics project using the **IBM Telco Customer Churn Dataset**. This project demonstrates the complete analytics workflow, including data validation in Excel, data cleaning and exploratory data analysis (EDA) in Python, and interactive dashboard development in Microsoft Power BI.


📌 Project Objective

The objective of this project is to analyze customer churn behavior, identify the key factors influencing customer retention, and present business insights through an interactive Power BI dashboard.

📈 Key Business Insights

- Customers with **Month-to-Month contracts** have the highest churn rate.
- **Electronic Check** users show higher churn compared to other payment methods.
- Customers using **Fiber Optic Internet Service** tend to churn more frequently.
- Long-term contracts (**One Year** and **Two Year**) improve customer retention.
- Monthly charges influence customer churn behavior.
